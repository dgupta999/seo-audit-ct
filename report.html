Critical Finding: Cleartrip's H1 price anchor is 45% higher than the market floor

Priority Gap Analysis
P1 = Fix this week. P2 = Fix this sprint. P3 = Next quarter.
P1 — Critical (This Week)
1

Add OG Tags — All Three Missing

Cleartrip has null ogTitle, ogDescription, ogImage. Every competitor has them. This means every social share of this page renders with no preview image or description — a dead link in WhatsApp, Facebook, LinkedIn. Fix is 3 lines of HTML.

2

Add Robots Meta Tag

Currently null. Add <meta name="robots" content="index, follow">. Google defaults to indexing without it, but explicit declaration is best practice and removes any ambiguity.

3

Fix 20 Missing Image Alt Texts

25% of 80 images have no alt attribute. Competitors: 0% missing. This affects accessibility (ADA/WCAG), image search ranking, and Core Web Vitals CLS scores. Audit scraped-data/cleartrip.html for all <img> tags without alt.

P2 — High Impact (This Sprint)
4

Revise H1 — Remove "Book", Lower Price Anchor

Change from "Book Mumbai to New Delhi Flight Tickets, Fares @₹6958 + 25% Off" to something like "Mumbai to New Delhi Flights — Fares from ₹4,800 + 25% Off with Cleartrip". This captures informational intent and resets the price perception anchor.

5

Add HowTo Schema for Booking Guide

MMT and Goibibo use HowTo schema — it's one of Google's richest SERP features for this query type. Cleartrip already has a "How to Book" H2 section. Wrap it in @type: HowTo with 5–7 steps. Low dev effort, high SERP visibility payoff.

6

Fix "New delhi" Capitalisation Bug

Throughout CT's page — H2s, H3s, meta desc — "New delhi" appears with lowercase 'd'. This looks like a template variable injection bug (New {{city}} → New delhi). Affects perceived quality and EEAT trust signals.

7

Content Depth Gap: +2,600 words needed

CT has 4,928 words vs MMT's 7,590 and Goibibo's 8,459. Add seasonal content: "Best time to fly Mumbai to Delhi", "Monsoon flight tips", "Festive season fares" — MMT uses this for HowTo schema that gets rich snippet placement.

Add Review / Rating Schema

Only Ixigo deploys a Product schema with ratings potential. Adding AggregateRating to the page — tied to CT's own review data — can surface star ratings in SERPs for this high-intent route. Stars in SERPs = +15–30% CTR uplift (industry benchmark).

Page Structure & Tonality Review

Tonality: Transactional vs Informational

Cleartrip's page opens aggressively transactional ("Book… Flight Tickets") — optimised for bottom-funnel users who are ready to buy. MMT and Goibibo open informational ("Mumbai to Delhi Flights") — this captures both top-funnel (planning) and bottom-funnel (booking) queries. For a route as competitive as BOM-DEL, informational framing captures 3–4x more query variations and still converts well because booking intent is implicit.


Recommendation: Shift to dual-intent framing. Lead with route + price + convenience, then transactional CTAs in the body.

Structure: CT Has the Best Bones

CT's page architecture is the strongest: good H2/H3 hierarchy, destination content (Mumbai + Delhi), booking guide, FAQ, airport information, price trends, airline comparison. Goibibo's zero-H2 page is actually architecturally inferior despite higher word count. CT just needs to fill the content gaps and fix the technical issues — the skeleton is solid.

Promo Code Strategy

CT meta: CTDOM — buried, single code. MMT meta: MMTDEAL + 5 USP trust signals (Free Cancellation, Instant Discount, 24x7, Cashback). EaseMyTrip: EMTFIRST + "No Convenience Fee" unique claim. CT's promo feels isolated vs competitors' stacked-USP approach. A promo code should be paired with urgency and at least 2 supporting trust signals in the meta.

Price Anchoring Strategy

The ₹6,958 anchor in CT's H1/title is the most damaging single issue. In SERP, searchers see 4–5 results. CT shows ₹6,958, MMT shows ₹4,800, Goibibo shows ₹4,800. Even if CT's actual available fares are equivalent, the perceived price gap creates an immediate CTR disadvantage. Price anchor in H1 should reflect the minimum available fare (₹4,800 range) not the specific flight shown. This is a live data injection problem worth solving in the template.
